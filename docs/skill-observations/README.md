# Skill observations

Notes the `skill-retro` skill writes when a session shows that one of this
engineer's skills, agents or CLAUDE.md should change: a user correction, a
missing step, a misfire, or a stable preference. One file per observation,
committed so it survives cloud containers. `skill-retro` in improve mode
turns open observations into a reviewed change on a branch.

Proposals for vendored skills, which a sync script would overwrite, go in
`upstream.md`.
